2026 한국체육산업개발 공공데이터 활용 경진대회 출품용 정적 웹. 최종 수상/실제 기관 서비스가 아님. 2026-11-20 작성.

## 실행

- **로컬:** `../올팍동행_v2_바로실행.html` 열기. 또는 `python3 -m http.server 8000`을 프로젝트 루트에서 실행해 `http://localhost:8000` 접속.
- **배포:** 공개 GitHub 저장소 `main`으로 코드를 올리고 `Settings > Pages > Source: GitHub Actions`를 선택한 뒤 `Actions > Public data refresh and Pages deployment > Run workflow` 실행. 성공하면 Settings > Pages에 나타난 **실제 URL**을 제출한다. 인터넷 배포는 현재 이 파일 묶음에서는 수행하지 않음.
- **시험:** `python3 -m unittest discover -s tests -v`; 브라우저 시연 테스트 `python3 tests/browser_smoke.py` (playwright와 chromium 필요, 외부 라이브러리는 배포 서비스에는 포함되지 않음).

### FAQ 원본 CSV 연동 (두 가지)

1. **시민/심사위원 브라우저 실증:** 데이터포털에서 공식 FAQ CSV를 다운로드 → 시민 화면 아래 `FAQ CSV 선택` → 현장 FAQ 검색 및 안내서/운영자 과제가 데이터 행 기준 즉시 재생성. UTF-8/CP949, 인용부호·쉼표·줄바꿈 처리. **파일 서버 전송/저장 안 함**.
2. **장기 운영 스냅샷:** 공식 CSV를 `data/source/faq.csv`로 두고 저장소 커밋(공개 파일로 게시됨) → Actions를 다시 실행하면 `data/snapshot.js`에 적용. 공개 자료의 이용 조건을 준수하고 개인정보가 포함되지 않았는지 검토한다. 이후 내용 변경 때 다시 다운로드하고 커밋.

### 공연 XML 연동

`EVENTS_API_URL`을 Actions Repository Secret에, 실제 응답으로 검증한 필드명을 `EVENTS_FIELD_MAP`에 예: `{"item":"item","title":"...","start":"...","end":"...","venue":"...","url":"..."}`로 설정한다. **이 예시는 실제 태그명이 아닌 매핑 형식**이며, 허위 API 사용 방지를 위해 스키마 확인 전 자동연동은 비활성화한다. 날짜는 `YYYY-MM-DD`만 승인한다.

## 개선된 핵심 기능

- 방문 목적/날짜/휠체어/유아차/교통수단으로 공식 FAQ 레코드를 필터링하는 근거형 체크리스트. 각 정보에 원문 링크와 레코드 ID를 부착하고 날짜 충돌을 표시함.
- 운영자 화면에서 공연 행사장 고유명과 접근성 FAQ 언급 여부를 **교차 조회**: 근거가 없는 장소를 검증 과제로 자동 등록. 이것은 **접근 불가 판정이 아니라 데이터 커버리지 검사**임.
- FAQ 필수필드 누락/중복, 공연 날짜 오류, 원본 CSV 미반영, 공연 API 미반영, 주차 스냅샷 없음·90분 초과 등 7개 규칙군에 근거 ID를 부착해 자동 진단하고 CSV를 내보냄.
- 시연본은 사용자 방문 조건·원본 CSV를 외부로 보내거나 서버 로그에 남기지 않음. TXT/CSV는 브라우저에서 생성함.

## 배포 / 유지 계획 (2028-12-31 목표)

- 정적 호스팅 GitHub Pages, 데이터베이스 및 상시 서버 불필요. Actions에서 공공데이터를 수집하고 최신 수집본을 저장소에 커밋한 다음 **dist/**만 배포. GitHub 공개 저장소의 현재 무료 이용 정책을 전제로 하며, 미래 정책 변경 시 무료 비용을 보장하지 않는다.
- 매월 사람이 공개 URL, API 원문, FAQ 다운로드 여부, 최근 Actions 실행 및 재활성화 상태를 점검하고 `OPERATIONS_LOG.md`에 날짜·결과를 남긴다. **GitHub 예약 실행은 공개 저장소가 60일간 비활성화되면 중단될 수 있음**. 크론 실행 지연·누락도 가능하므로 자동 수집만 의존하지 않는다.
- 매분기 공연장 접근성 근거, 자주 묻는 질문 원본, 데이터 정의를 확인. 매년 소스코드 백업과 대체 무료 정적 호스팅 이관을 연습.
- 운영 비용은 현재 정책 조건하에서 호스팅 0원을 목표로 하나 인력 점검 비용·플랫폼 정책 변경 위험은 별도.
